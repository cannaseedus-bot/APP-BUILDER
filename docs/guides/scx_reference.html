SCX Reference

SCX (Scripting Command eXtensions) is the symbolic action layer used across ASX and Micronaut systems.

Core Symbols

# → user/actor
@ → network/internet
$ → currency/tokens
% → database/storage
& → location/route
* → time/timestamp
^ → AI/agent
! → alert/notify
? → query/request

Action Verbs

(>) send
(<) receive
(+) create
(-) remove
(=) assign
(%) save
(x) kill/destroy
(∂) update
(∞) loop

General Syntax

subject symbol action object
#player (∂) health = -10

Examples

#player (+) $wallet
#player (>) ^assistant "analyze area"
%logs (+) "entered_room"
!ui (>) "warning: low health"

Extended Examples (50+)

#player (∂) stamina = -3               // decrease stamina
#player (>) ^coach "advise rest"       // ask agent for coaching
#enemy (x)                            // remove enemy
&market (>) $payment                   // route to payment
^mx2php (>) %db.users                  // backend agent writes to DB
%local.settings (∂) theme = "dark"     // update UI setting
!ui (>) "mission started"             // notify user
#faction (∞) ^qwen "evaluate territory" // AI strategic loop
#trader (>) $inventory "add:water"    // add item to shop
%logs (+) {event:"door_open"}         // append log
