🎯 Mission

ASX is a JSON-first, framework-free runtime. One file ships an app: $state, $routes, $effects, plus optional $cipher. The engine interprets declarative JSON + SCX strings at raw JS speed.

📡 Reactive Binding

Bind DOM elements directly to $state paths — no framework required.

<strong>Score:</strong> <span data-bind="user.score"></span>
<button id="add">Add +5</button>
// Engine snippet
function updateBindings(state){
  document.querySelectorAll("[data-bind]").forEach(el=>{
    const path = el.getAttribute("data-bind").split(".");
    let val = state; for(const p of path){ if(val && p in val) val = val[p]; }
    el.textContent = val;
  });
}

Why: Declarative, resilient, very small. Works offline and scales.

🧠 SCX Grammar (Inline Control Flow)

TokenMeaningJS Equivalent
(?)ifif (cond)
(∴)thenthen block
(¬)elseelse
(⊕)incrementx++ / += 1
(💬>)messagenotify/log
// Inside $effects.run
"(?) user.score ≥ 100 (∴) (💬>) '🎉 Level up!' (⊕) user.score"

SCX strings are tokenized and executed in a sandbox — only whitelisted verbs/operators are allowed.

🔑 Cipher & Key Rotation

Session-specific dialects via a CipherMap. Pair with a time-based key for automatic rotation.

// Example map (static demo)
const CipherMap = { "(?)":"if", "(∴)":"then", "(⊕)":"increment", "(💬>)":"message" };
// Rotation policy (pseudocode)
derivedKey = SHA256(baseKey + timeSegment + salt);
CipherMap = makeMapFromKey(derivedKey);

Do not eval arbitrary strings. Always parse SCX tokens and dispatch to safe handlers.

✅ Best Practices

  • Initialize all state; avoid undefined paths.
  • Keep SCX verbs minimal and explicit.
  • Keep splash short; fade to UI promptly.
  • Use key rotation for any secret-bearing fields.
  • Never use eval; only parse whitelisted tokens.
