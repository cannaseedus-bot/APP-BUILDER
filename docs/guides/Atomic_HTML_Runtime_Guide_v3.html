Atomic HTML — Runtime Ops Guide v3

Purpose. This is the online, operations‑focused reference for running Atomic HTML apps in production with the ASX Runtime (Liquid Atomic). Use alongside the Local HTML Guide when authoring offline.

✨ What's New in v3

  • NEW Dual‑deliverable model: Runtime Ops (this page) + Local Authoring (≤40KB).
  • NEW Atomic.init() boot contract and lifecycle hooks (beforeMount, mounted, ready).
  • NEW Micro reactive bindings via data-bind + Atomic.update().
  • NEW SCX token grammar + optional Symbolic Cipher rotation (session/5‑min).
  • NEW Ops API: Atomic.load(url), Atomic.set(path,val), Atomic.route(name), Atomic.effect(run,ctx).

🧭 Concept

Atomic HTML = one self‑contained HTML file that can host a full ASX app. It loads a JSON shell (.asx) and renders with no framework. Use it as your universal viewer, docs shell, or demo runner.

Authoring
Use Local Guide (≤40KB) offline to write and preview.
Runtime

🚀 Runtime Boot (Ops)

Embed a fake‑boot splash, then mount UI.

<div id="splash">Booting…</div>
<main id="app" hidden></main>
<script>
const Atomic = {
  state:{}, effects:[], routes:{}, readyCbs:[],
  init({asx="/app.asx", onReady=()=>{}}={}){
    fetch(asx).then(r=>r.json()).then(cfg=>{
      this.cfg=cfg; this.state=cfg.$state||{}; this.routes=cfg.$routes||{};
      setTimeout(()=>{ // fake boot
        document.getElementById('splash').remove();
        document.getElementById('app').hidden=false;
        this.mount(); onReady(this);
      },800);
    });
  },
  mount(){ this.renderRoute(Object.keys(this.routes)[0]||"home"); },
  renderRoute(name){
    const root=document.getElementById('app');
    root.innerHTML = "<h2>"+(name||"home")+"</h2>";
    this.update();
  },
  set(path,val){ const seg=path.split('.'); let o=this.state; 
    while(seg.length>1){const k=seg.shift(); o=o[k]=o[k]??{};} o[seg[0]]=val; this.update(); },
  update(){
    document.querySelectorAll("[data-bind]").forEach(el=>{
      const p=el.getAttribute("data-bind").split('.'); let v=this.state;
      for(const k of p){ v = v?.[k]; } el.textContent = v ?? "";
    });
  },
  route(name){ this.renderRoute(name); },
  effect(run,ctx={}){ console.log("run SCX:",run,ctx); /* plug parser */ },
  onReady(cb){ this.readyCbs.push(cb); }
};
Atomic.init({asx:"/app.asx", onReady:()=>console.log("ready!")});
</script>

🧠 SCX / Cipher

TokenMeaningExample
(?)if(?) user.score >= 100 (∴) (💬>) "Level up!"
(∴)thenthen‑block
(¬)elseelse‑block
(⊕)increment(⊕) user.score

For production, encode SCX with a rotating alias map; decode server‑side, never eval strings.

☁️ Deploy & Versioning

  1. Commit both deliverables: atomic-runtime.html and atomic-local.html.
  2. Serve atomic-runtime.html behind your CDN. Cache for 1h; revalidate on deploy.
  3. Keep app.asx immutable per release; bump querystring for hotfixes.
  4. Optional: preload assets with <link rel="preload"> for splash.

❓ FAQ

Q: Can I combine with Stripe/Coinbase add‑ons?
A: Yes—expose minimal bridges and trigger via $effects.run.

Q: Will this run offline?
A: Yes—pair with a service worker and embed app.asx inline or precache it.
