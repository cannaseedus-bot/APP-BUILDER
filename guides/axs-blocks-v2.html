ASX Universal UI Language

ASX Design Kit v2 — Atomic, Mesh-Aware, K’uhul-Ready

This design kit defines the **visual grammar** of ASX OS: colors, atomic CSS, cards, buttons, K’uhul glyphs, SCXQ2 blocks, DNS views, REST mesh consoles, and HUD layouts. It is meant to live inside a **3-file OS** and boot as a studio tape.

Rule of Three index.html · sw.js · manifest.json
KLH backend: KLH = mesh router + backend name
K’uhul: glyph engine for execution & UI blocks
SCXQ2: compression / cipher UI integration

03 · Core Components

Cards, buttons, glyphs, and status indicators — the building blocks that every ASX OS view should use.

ASX Panel
.asx-card
Generic glass-morphic container for system views, tape info, agent status, or REST output. Stack these to build dashboards.
Buttons
.asx-btn*
Use .asx-btn for neutral, .asx-btn-primary for CTAs, and ghost variants for low-priority actions.
Status Dots
Kernel / Mesh / DNS
Use small colored dots for live backend status: green (ok), blue (mesh), amber (warning), red (down). These map directly to KLH + K’uhul + DNS health.
Glyph Items
K’uhul / SCXQ2
Glyph cards visually encode operators: Pop, Wo, Sek, Ch’en, Xul, (?) , (∴), ⟁. These show up in execution and cipher diagrams.
