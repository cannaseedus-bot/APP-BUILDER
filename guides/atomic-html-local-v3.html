Atomic HTML — Local Authoring Guide v3

Why

Write and preview ASX apps fully offline. One HTML file + one JSON (app.asx) is enough.

Quick Start

<!-- atomic-local.html -->
<div id="splash">Booting…</div>
<main id="app" hidden>
  <h3>Score: <span data-bind="user.score"></span></h3>
  <button id="plus">+5</button>
</main>
<script>
// Minimal Atomic (tiny, no deps)
const A={S:{},R:{},init(u="app.asx"){fetch(u).then(r=>r.json()).then(j=>{A.C=j;A.S=j.$state||{};A.R=j.$routes||{};setTimeout(()=>{s.remove();m.hidden=0;A.U()},600)})},
U(){document.querySelectorAll("[data-bind]").forEach(e=>{let v=A.S;e.getAttribute("data-bind").split(".").forEach(k=>v=v&&v[k]);e.textContent=v??""})},
set(p,v){let o=A.S,a=p.split(".");while(a.length>1){const k=a.shift();o=o[k]=o[k]||{}}o[a[0]]=v;A.U();}
};
const s=document.getElementById("splash"),m=document.getElementById("app");
A.init(); plus.onclick=()=>A.set("user.score",(A.S.user?.score||0)+5);
</script>

Tip: keep this file lean; use PNG/SVG assets externally.

app.asx (example)

{
  "$schema":"asx-shell-v1",
  "$state":{"user":{"score":0}},
  "$routes":{"home":{}}
}

SCX (optional)

Inline control strings like (?) user.score ≥ 10 (∴) (💬>) "Ding". Parse safely; no eval.

Build & Ship

  1. Keep this HTML ≤ ~40KB (no heavy fonts, no libs).
  2. Host atomic-runtime.html for production; keep this one for local notes.
  3. Version bump by changing app.asx?v=3.
