[Pop lexicon_semantic_ingest_text]
  [Wo @text]→[Sek tokenize_words]→[Ch'en words]
  [Wo 4]→[Ch'en window]

  [Sek each_index words:
    [Gw i tok]
    [Sek lexicon_word_update tok]
    [Sek context_window words i window]→[Ch'en ctx]
    [Sek lexicon_coocc_update tok ctx]
  ]

  [Xul return {
    "@type":"lexicon_semantic_ingested",
    "tokens":[Sek length words],
    "window":window
  }]
[Xul]

[Pop lexicon_semantic_rebuild_all]
  [Yax "lexicon_coocc"]→[Sek mx2db_get_all]→[Ch'en all]
  [Wo {}]→[Ch'en sem]

  [Sek each_record all:
    [Gw rec]
    [Sek lexicon_semantic_from_coocc rec]→[Ch'en vec]
    [Sek map_set sem rec.token vec]
  ]

  [Yax "lexicon_semantic"]→[Wo sem]→[Sek mx2db_put]

  [Xul return {
    "@type":"lexicon_semantic_rebuilt",
    "tokens":[Sek length all]
  }]
[Xul]

[Pop meta_prompt_synthesize_semantic]
  [Yax "prompt_blocks"]→[Sek mx2db_get]→[Ch'en P]
  [Yax "reasoning_patterns"]→[Sek mx2db_get]→[Ch'en R]
  [Yax "lexicon_semantic"]→[Sek mx2db_get]→[Ch'en S]

  [Wo [Sek select_semantic_anchors S 12]]→[Ch'en anchors]

  [Wo {
    "task":"@infer",
    "attributes":[Sek top_k P 20],
    "relations":[Sek top_k P 15 phrase],
    "reasoning":[Sek top_k R 10],
    "semantic_anchors":anchors,
    "@control":["@coherent","@semantic_dense","@chain_reasoning"],
    "@variable":{"@entropy":0.37,"@innovation":0.44}
  }]→[Ch'en final]

  [Xul return final]
[Xul]
@grams → vectors
Unigrams, bigrams, trigrams feed co-occurrence counts. XCFE treats them as @variable state for semantic flow.
Semantic Anchors
Top-scoring features in lexicon_semantic become anchors that bias prompts toward stable, domain-correct meanings.
Prompt Gravity
Similar tokens share features, so prompts “fall” into consistent frames without neural embeddings – pure KUHUL PI gravity.
