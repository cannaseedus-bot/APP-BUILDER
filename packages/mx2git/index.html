Features
🔒
Secure Token Storage
GitHub tokens stored securely in ASX-RAM virtual filesystem, never exposed to network.
⚡
Pull / Push Sync
Bidirectional sync between GitHub repos and ASX-RAM with automatic conflict detection.
📦
Full Repository Clone
Clone entire repositories into ASX-RAM for offline editing and multi-file operations.
🤖
Agent-Driven Operations
agent.git.sync handles all GitHub operations with KUHUL pipeline integration.
📋
XJSON Everywhere
All data stored in XJSON format with @context, @law, @v for semantic clarity.
🌐
Offline-First
Service worker architecture ensures full functionality offline with cache-first strategy.
API Endpoints
POST /api/mx2git/save-credentials
Save GitHub token to ASX-RAM
POST /api/mx2git/pull
Pull file from GitHub to ASX-RAM
POST /api/mx2git/push
Push file from ASX-RAM to GitHub
POST /api/mx2git/clone
Clone full repository to ASX-RAM
POST /api/mx2git/import-github
Register repository as project
GET /api/mx2git/projects
List all registered projects
